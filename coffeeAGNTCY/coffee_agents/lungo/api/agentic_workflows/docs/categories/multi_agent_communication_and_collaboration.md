# Multi-Agent Communication & Collaboration

How agents coordinate through conversation, groups, consensus, or trusted boundaries. Patterns here wire several
specialists into shared channels where they can see one another's contributions, refine offers together, or converge on
a single outcome without a permanent hub-and-spoke turn order.

**Peer Group** is the flat, group-addressable conversation surface. **Secure Group Collaboration** extends that shape
with authenticated membership, scoped messages, and attributable speech inside a trusted boundary. **Decentralized
Consensus Agents** exchange beliefs until a forecast or allocation converges under explicit stopping rules.

**Patterns:** Peer Group, Secure Group Collaboration, Decentralized Consensus Agents

**Not to be confused with Orchestration & Control Flow** — collaboration patterns define *how peers interact in the
open*. Orchestration patterns define *who owns the saga, sequencing, and recovery*.
