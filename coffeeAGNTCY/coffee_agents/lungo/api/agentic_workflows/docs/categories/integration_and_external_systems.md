# Integration & External Systems

Connecting agent reasoning to systems of record and trusted external evidence. Patterns here treat enterprise tools,
tariff engines, and similar backends as first-class inputs—normalized, auditable facts agents can cite instead of prose
memory or guessed numbers.

**Patterns:** Agent-to-System Bridge

This category is intentionally narrow today; it marks where *external system invocation* lives distinct from internal
memory (Internet of Cognition) or cataloged agent selection (Discovery, Routing & Composition).
